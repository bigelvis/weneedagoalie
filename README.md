# weneedagoalie.com

Hockey team ↔ goalie matchmaking for the DC metro area.

## Pages
- `/` — Homepage
- `/goalie-signup.html` — Goalie registration
- `/find-goalie.html` — Team goalie request
- `/admin/` — Admin panel

## Stack
- HTML/CSS/JS (no framework)
- Firebase Firestore (database)
- Resend (email notifications)
- Netlify (hosting)

## Setup
1. Copy `js/firebase-config.js` and add your Firebase credentials
2. Deploy to Netlify
3. Point weneedagoalie.com DNS to Netlify
